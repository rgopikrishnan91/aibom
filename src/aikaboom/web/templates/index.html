Heads up. Recursive generation walks the dependency tree — each trainedOn / testedOn / dependsOn / sourceInfo target produces another BOM, which may itself reference more dependencies. AIkaBoOM keeps a unique-target set so each artefact is fetched once, and stops at Depth or when the set is exhausted. Higher depths cost more time, bandwidth, and LLM tokens.
